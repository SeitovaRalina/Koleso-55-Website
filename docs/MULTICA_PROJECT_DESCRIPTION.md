Сайт экскурсий «Колесо путешествий 55». Проект объединяет React/TypeScript frontend, Django API и FastAPI recommender. Работа ведётся отдельными задачами: одна задача — один проверяемый результат.

Источник правил: `AGENTS.md`. Актуальное состояние production и ограничения: `docs/AGENT_HANDOVER.md`. Продуктовые решения: `docs/PRODUCT_DECISIONS.md`. Остальные документы использовать по теме задачи; при расхождении сверять с текущим кодом и актуальным handover.

Для каждой задачи указывайте наблюдаемое и ожидаемое поведение, границы изменений и критерии приёмки. Результат агента проверяется человеком. Привязанный локальный Git-репозиторий используется в режиме worktree; запуск агента не означает разрешения на деплой или слияние ветки.
