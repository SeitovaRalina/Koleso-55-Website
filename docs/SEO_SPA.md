# Поисковые метаданные и SPA

Главная страница отдаёт `title`, `description`, Open Graph и `lang=ru` прямо в `frontend/index.html`. При переходе внутри приложения `RootLayout` обновляет заголовок, описание и OG-метаданные для `/about`.

Текущий Vite/React сайт — клиентская SPA. Nginx отдаёт один `index.html` по прямому запросу `/about` и другим маршрутам. Поэтому робот без выполнения JavaScript получает метаданные главной страницы, а не отдельные метаданные `/about`. Для надёжной индексации внутренних страниц нужен prerender или SSR с отдельным HTML для каждого публичного маршрута. Перед внедрением проверить прямые HTTP-ответы маршрутов и предпросмотр ссылок.

Текст поискового сниппета выбирает поисковая система; обновление метатегов не гарантирует его немедленного изменения.
