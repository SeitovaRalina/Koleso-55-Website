Важное условие: сейчас слот хранит только дату и время начала. Для точного интервала нужно добавить дату и время окончания в Admin/API и проверить, что окончание позже начала. У старых слотов без окончания показывать только известное начало.

Для многодневной программы «2 дня» означает два календарных дня; число дней не следует получать округлением часов. Цену брать из действующих типов билетов с учётом цены выбранного слота.
