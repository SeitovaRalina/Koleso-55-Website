# Multica integration

Multica project configuration mirrors repository policy but synchronises manually. Keep task text free of credentials, private hosts and personal data.

- Group small related bugs into one observable outcome.
- Keep unrelated/risky changes separate.
- Move finished change to human review; only human review marks it done.
- Attach UI screenshots or backend test/contract evidence to PR.
- Customer question blocks only affected task; resume same task after answer.

Check current Multica UI for branch, worktree and concurrency configuration.
