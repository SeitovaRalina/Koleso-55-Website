Период работ: октябрь–ноябрь 2026.

В отчёте собраны исправления, сделанные по обращениям заказчика и по находкам в
процессе проверки. Каждый пункт ниже готов к приёмке на опубликованном сайте.

## Как проверить результат

1. Открывайте указанные страницы в обычном браузере и на телефоне.
2. Выполняйте проверку из третьей колонки таблицы.
3. Для форм используйте тестовые ФИО, телефон и email, а не реальные данные
   клиентов.
4. После проверки отметьте замечания рядом с конкретным пунктом — это позволит
   быстро собрать следующий список правок.

## Дополнительные изменения, включённые в результат

- В шапке сохранены логотип и навигация «Каталог», «Сертификаты», «Новости»,
  личный кабинет; лишний текст рядом с логотипом удалён.
- «Афиша активностей» больше не ведёт на отдельную устаревшую страницу, а
  открывает каталог.
- Для длинных списков категорий в каталоге доступно раскрытие полного списка и
  поиск по названию.
- В карточках программ информация о времени не дублируется, а цена отображается
  честно в зависимости от количества активных тарифов.
- Поисковое описание сайта обновлено технически; сам поисковый сниппет меняется
  только после переобхода со стороны поисковой системы.

## Текущие правила работы сайта

- Онлайн-оплата пока не используется: посетитель оставляет заявку, после чего с
  ним связывается менеджер.
- Бронирование не уменьшает количество мест автоматически.
- Для связи по вопросу посетитель выбирает удобный способ; обязательным является
  соответствующий контакт.
- Вопросы, заказные экскурсии и сертификаты хранятся отдельно, но клиент видит
  их в общем разделе «Мои заявки».
